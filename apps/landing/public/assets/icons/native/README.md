# Zeron native icons

These files are exact copies of `crates/ui/assets/icons/` and are synchronized by
`seo/icons.mjs` when building within the repository. Standalone landing deploys
use this mirror. The icon parity test guards against drift.

Solar Icons (Linear) by 480 Design: https://github.com/480-Design/Solar-Icon-Set
Licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
Geometry is unchanged; the website applies theme colors through CSS masks.
Zeron's custom control glyphs follow `crates/ui/src/icons.rs`.

GitHub, Discord, X and operating-system logos are separate brand assets; they
are not interface glyphs and remain their respective owners' marks.
